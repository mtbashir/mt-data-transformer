Gap-fill rules

Rows that Master Data expects but New Data never reported get built from the Template + Past Data file.

Where filled values come from

Both pools are searched. A gap in one city borrows from the same product in another city or date — New Data for current figures, Template + Past Data for anything New Data never reported. Whichever supplies the numbers, the filled row always keeps its own date from New Data's reporting range.

Matching order

A missing row is matched on all dimensions first. If the Template + Past Data file has nothing, the next looser match is tried.

How each measure is filled

By default a filled row copies the past value as-is. Add a rule to vary it — for example a price within one rupee of the last one.
